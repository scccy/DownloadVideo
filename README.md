# 视频多平台下载服务 (Video Platform Service)

## 项目简介
一个基于微服务架构的视频多平台下载服务，支持多个主流视频平台的内容获取和下载。

## 技术栈
- JDK 21
- Spring Boot 3.2.5
- Spring Cloud 2023.0.1
- Spring Cloud Alibaba 2023.0.1.0
- Maven 3.9.9
- MongoDB 6.0.12
- Redis 7.2.3
- MinIO
- Kafka
- Docker

## 项目结构 

## 核心功能

### 1. 平台服务
- 多平台支持 (B站、YouTube、TikTok、抖音)
- 统一的视频信息获取
- 平台特定的解析逻辑
- 认证和授权管理

### 2. 视频基础服务
- 视频元数据管理
- 媒体格式处理
- 统一存储接口
- 视频信息提取

### 3. 下载服务
- 多线程下载
- 断点续传
- 代理池管理
- 任务调度

### 4. 网关服务
- 统一接入点
- 路由管理
- 负载均衡
- 服务发现

## 已完成功能 ✅

### 基础设施
- 基础配置框架
  - CommonConfig - 通用配置（集成配置管理）
  - FeignConfig - Feign客户端配置（HTTP客户端配置，包含重试、超时等）
  - FastJson2Config - JSON配置（序列化/反序列化）
  - MybatisPlusConfig - MyBatis-Plus配置（数据库访问层）
  - Knife4jConfig - API文档配置（OpenAPI 3.0）
  
- 异常处理机制
  - BusinessException - 业务异常定义（统一业务异常）
  - GlobalExceptionHandler - 全局异常处理（统一异常响应）
  
- 工具类支持
  - TraceIdUtil - 链路追踪（请求链路跟踪，支持全链路ID传递）
  - LogUtil - 日志工具（统一日志处理，支持MDC）
  - JsonUtil - JSON工具（数据转换，支持类型转换）
  - IpUtil - IP工具（主机名和IP地址获取）
  
- HTTP客户端
  - FeignErrorDecoder - Feign错误处理（HTTP错误统一处理，支持业务异常转换）
  - 统一的请求响应处理（标准化接口交互）
  - OkHttp集成（高性能HTTP客户端）

- 通用模型
  - BaseEntity - 基础实体类
    - 创建时间（自动填充）
    - 更新时间（自动填充）
    - 创建节点（自动填充）
    - 更新节点（自动填充）
    - 逻辑删除（自动填充）

### 数据库支持
- MyBatis-Plus 集成
  - 通用 CRUD 接口
  - 分页插件
  - 逻辑删除
  - 自动填充
  - 乐观锁插件
  - 性能分析插件（开发环境）

### API文档
- Knife4j 集成
  - OpenAPI 3.0 规范
  - 接口文档自动生成
  - 在线调试功能
  - 文档导出
